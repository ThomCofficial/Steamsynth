# SteamSynth — Botanical hardware UI rebuild

This editor is **not** a flattened image with invisible controls painted on top.

- `plate.jpg` holds only stationary parchment, engraved scales, botanical scenery and mechanical housings. The keys, knob caps, tabs, preset title, LED and needles are removed from the stationary plate.
- `hardware.png` contains independent RGBA hardware sprites: five annular moving brass rings, five stationary engraved botanical medallions, nine small brass knobs, a rotating pollination ring, four tab switches in two states, preset hardware, a separate undo switch, independent ivory/ebony key sprites, LED and lamp flame.
- `PluginEditor.cpp` renders each knob from its own sprite and JUCE SliderAttachment. Only the rim and its physical marker rotate; the botanical inlay remains fixed. The keyboard is individually drawn with real black-key hit testing and MIDI note illumination. The lamp, meter, LED and oscilloscope animate independently.
- FX, Motion and Pollinate tabs update their own parameter bindings and printed labels; the underlying DSP remains unchanged in this UI-only revision.
- The new `SteamSynth-UI-smoke.png` generated by the plugin smoke test can be inspected in GitHub Actions artifacts. Real Cubase interaction still requires a host test.

To regenerate the atlas from the approved reference: `python build_assets.py` (local authoring script; not needed to build the plugin).
